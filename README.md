# 🎓 Student Management System

A console-based Student Management System developed using Python. This project allows users to manage student records through a simple menu-driven interface.

## ✨ Features

- **Add Student:** Register new students with ID, name, age, course, and marks.
- **Duplicate ID Prevention:** Prevents registration with an existing student ID.
- **View Students:** Display all registered student records.
- **Update Student:** Modify individual details or update all student information.
- **Delete Student:** Remove student records using their ID.
- **Menu-Driven Interface:** Navigate through the application using simple menu options.

## 🛠️ Technologies Used

- Python 3
- Lists
- Dictionaries
- Functions
- Loops
- Conditional Statements

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Subha05x/student-management-system.git
```

### 2. Navigate to the project folder

```bash
cd student-management-system
```

### 3. Run the application

```bash
python3 main.py
```
